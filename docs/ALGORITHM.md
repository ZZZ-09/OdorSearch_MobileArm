# 气味源搜索算法说明（改进版）

## 1. 硬件配置

根据“基础算法设计.docx”与“机器人参数.txt”中的要求，机器人系统由以下部分组成：

- **移动小车（AgileX UMR）**：
  - 四个角各安装 1 个固定气味传感器；
  - 可全向移动，最大速度 1.5 m/s；
  - 车体尺寸 0.83 m × 0.54 m × 0.41 m。

- **机械臂（RealMan RM65-6F-V）**：
  - 6 自由度，工作半径约 0.6385 m；
  - 末端安装 1 个气味传感器；
  - 末端集成视觉相机，用于发现/确认气味源实体。

共 5 个气味传感器：4 角固定 + 1 末端移动。

## 2. 状态机

搜索算法采用有限状态机，状态转移如下图所示：

```text
                    看到潜在源
+-------------+    ---------------->    +----------------+
| RANDOM_WALK |                         | VISUAL_APPROACH|
+------+------+    <----------------    +--------+-------+
       | 视觉丢失/无气味                          |
       |                                         | 末端检测到气味
       |                                         v
       | 四角检测到气味      +-------------+     +-------------+
       +-------------------> |BASE_TRACKING|---->| ARM_TRACKING|
                             +-------------+     +------+------+
                                                        |
                      多模态/严格嗅觉确认                v
                                               +-------------+
                                               |  FINISHED   |
                                               +-------------+
```

## 3. 各状态行为

### 3.1 Random Walk（随机游走）

目标：在没有任何传感器检测到气味时，快速覆盖仓库空间，避免重复与绕圈。

- **前进策略**：优先沿当前偏航方向直线前进；若前方有障碍物、边界或卡住，则通过 360° 多角度扫描选择最佳方向。
- **覆盖激励**：扫描方向时，对未访问过的网格单元给予加分，避免重复访问。
- **高度分层**：机械臂按 `low / mid / high` 三组预设姿态循环抬升，实现对不同高度层的覆盖。
- **标记清除**：当机械臂高度层切换时，清除该高度层的已访问标记，允许在新高度重新扫描。

### 3.2 Visual Approach（视觉优先）

触发条件：末端相机看到潜在气味源实体（在视野内且未被遮挡）。

- **优先级**：视觉信号优先级最高，可从 Random Walk / Base Tracking / Arm Tracking 任何状态切入。
- **基座运动**：小车向气味源方向移动，越近速度越慢，避免冲过头。
- **机械臂运动**：末端直接指向气味源实体位置。
- **状态转移**：一旦末端传感器检测到气味，转入 `ARM_TRACKING`；若视野丢失且长时间无气味，回到 `RANDOM_WALK`。

### 3.3 Base Tracking（基座追踪 / 移动探测器引导）

触发条件：四角固定传感器中至少一个检测到气味，但末端移动传感器尚未检测到。

- **方向选择**：选择四角中浓度最高的传感器作为引导方向。
- **移动探测器**：末端传感器（机械臂末端）向该固定探测器所在方向延伸，并沿该方向外推一小段，直到末端传感器也检测到气味。
- **基座辅助**：小车同时向该角方向缓慢平移并调整朝向，协助末端进入烟羽。
- **状态转移**：一旦末端传感器检测到气味，立即转入 `ARM_TRACKING`。

### 3.4 Arm Tracking（末端追踪）

触发条件：末端传感器已检测到气味。

- **目标点生成**：
  - 距离源较远（> 1.0 m）时，优先使用源方向提示；若局部浓度梯度可靠（与源方向一致或梯度很强），则混合梯度方向；
  - 距离源较近（< 1.0 m）时，直接将气味源位置作为目标点，避免局部梯度误导。
- **基座主动跟进**：根据与源的距离动态调整基座移动增益：
  - > 2.0 m：0.08 m/步；
  - 1.0–2.0 m：0.05 m/步；
  - 0.5–1.0 m：0.02 m/步；
  - < 0.5 m：0.005 m/步。
- **局部极值逃离**：若末端浓度持续高于阈值但位置几乎不动（陷入局部高浓度平台），则转入 `LOST` 并标记当前位置，随后重新随机游走。
- **机械臂控制**：使用阻尼最小二乘数值 IK，将末端传感器移向目标点，每步关节增量限制在 8° 以内，并裁剪到关节限位。

### 3.5 Finished（终止）

本版本改为**嗅觉主导结束**，视觉仅作为辅助加速条件：

1. **嗅觉主导判据**（主要）：
   - 末端浓度 `ee_ppm > 1000 ppm`（约 200 倍检测阈值），连续 40 步；
   - 末端位置为局部浓度高点：在 ±x、±y、±z 六个方向采样，ee 处浓度不低于所有相邻点（允许噪声容差）；
   - 最近 40 步内基座水平位移 < 0.20 m，说明已收敛到源附近而非穿过 filament。

2. **视觉辅助判据**（可选）：
   - 末端相机看到气味源实体；
   - 视觉测距 < 0.8 m；
   - 末端浓度 > 10 倍检测阈值；
   - 连续 3 步满足上述条件。

以上条件均不使用真实源位置或源强度。机器人声明找到源时，记录当前末端传感器位置作为 `declared_source_position`，供独立评估体系使用。

## 4. 视觉传感器的作用

根据 OdorSim 项目对末端相机的使用方式，本项目加入简化视觉模型：

- 相机安装在机械臂末端法兰盘，光轴沿法兰 z 轴；
- 检查气味源实体是否在视场角（水平 80°、垂直 60°）和最大探测距离（3 m）内；
- 通过射线检测判断视线是否被障碍物遮挡；
- 视觉发现潜在源时优先引导搜索，视觉确认源实体且浓度足够高时可触发结束。

视觉信息既作为“搜索引导”信号，也作为“结束确认”信号，与嗅觉多模态融合后降低误报。

## 5. 障碍物规避

- **基座碰撞盒**：车体近似为一个轴对齐包围盒，机械臂安装立柱近似为一个小包围盒。
- **机械臂碰撞检测**：沿各连杆采样若干点，检查是否进入任何障碍物。
- **动作回退**：若执行动作后检测到碰撞，立即回退基座命令，机械臂命令保留。
- **随机游走避障**：通过前方探测与多角度扫描避免进入障碍物；选择方向时额外偏向仓库中心，减少角落绕圈。

## 6. 气味扩散模型

本项目使用简化的三维高斯烟羽模型：

- 下风向浓度高、上风向快速衰减；
- 扩散半径随下风向距离线性增大；
- 加入低频正弦湍流扰动，模拟真实环境中烟羽的时变特性；
- 传感器读数进一步加入高斯白噪声和一阶动态滞后。

在 OdorSim 平台中，该解析模型通过 `odor_sim_adapter.py` 替换为 GADEN 的实时 `/odor_value` 服务，搜索逻辑保持不变。

## 7. 独立评估体系

`src/evaluation.py` 提供与搜索决策独立的评估：

- 机器人声明找到源时，使用 `declared_source_position` 计算与真实源位置的距离；
- 未声明找到时，使用最终末端传感器位置作为 fallback；
- 距离 < `success_distance_threshold`（默认 1.0 m）即判定成功。

该评估用于仿真成功率统计，不影响机器人实时决策。

## 8. 算法参数调参指南

| 参数 | 文件 | 默认值 | 说明 |
|------|------|--------|------|
| `source_distance_threshold` | `search_algorithm.py` | 0.55 m | 几何指向成功距离（内部参考） |
| `success_distance_threshold` | `search_algorithm.py` / `evaluation.py` | 1.0 m | 独立评估成功距离阈值 |
| `concentration_saturation_threshold` | `search_algorithm.py` | 0.20×源强度 | 严格嗅觉确认阈值 |
| `detection_threshold` | `warehouse.yaml` | 5.0 ppm | 传感器触发阈值 |
| `source_strength` | `warehouse.yaml` | 3000.0 ppm | 气味源释放强度 |
| `wind` | `warehouse.yaml` | [0.5, -0.2, 0.0] | 环境风场 |
| `random_walk_speed` | `search_algorithm.py` | 0.08 m/步 | 随机游走速度 |
| `cell_size` | `search_algorithm.py` | 0.8 m | 覆盖网格尺寸 |
| `_steps_before_level_switch` | `search_algorithm.py` | 120 步 | 机械臂高度层切换周期 |

调参建议：
- 若源位置较高，需确保机械臂可达；RM65 从基座算最大垂直 reach 约 1.05 m。
- 若仓库更大或源更弱，可适当提高 `source_strength` 或降低 `detection_threshold`。
- 若机器人频繁碰撞，可降低 `random_walk_speed` 或增大探测距离。
- 若随机游走重复搜索同一区域，可减小 `cell_size` 或增大 `visited_penalty`。
